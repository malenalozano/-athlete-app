[EJ-PROG-1] Sistema de registro de ejercicios desde Diario > Entreno Libre
----------------------------------------------------------------------
OBJETIVO: El usuario registra los ejercicios que hizo en una sesión de fuerza
desde la pestaña "Entreno Libre" de Diario. La interfaz muestra la lista de
ejercicios activos del grupo que corresponde al día (Push/Pull/Pierna según
el plan), y el usuario selecciona cada ejercicio, mete kg y series realizadas.

FLUJO DETALLADO:
1. El usuario abre Diario > Entreno Libre un día de fuerza
2. El sistema detecta qué tipo de sesión de fuerza toca hoy (Push/Pull/Pierna)
   consultando plan_entrenamiento WHERE fecha=hoy AND usuario_id=1
3. Aparece la lista de ejercicios ACTIVOS de ese grupo (de ejercicios_catalogo)
4. Para cada ejercicio hay:
   - Nombre del ejercicio (no editable, referencia)
   - Campo "Series completadas" (número)
   - Campo "Repeticiones" (número)
   - Campo "Peso (kg)" (número)
   - Toggle "¿Completaste todas las series?" (sí/no)
5. Al guardar, se insertan registros en historial_ejercicio
6. Si el toggle "completadas" = SÍ → se marca el ejercicio con subir_peso=1 en ejercicios_catalogo
7. Si el toggle = NO → subir_peso se queda en 0

CAMBIOS DE BD NECESARIOS:
- ALTER TABLE ejercicios_catalogo ADD COLUMN subir_peso INTEGER DEFAULT 0
  (1 = la próxima sesión hay que subir peso, 0 = mantener)

CAMBIOS BACKEND NECESARIOS:
- El endpoint POST /ejercicios/serie ya existe y guarda en historial_ejercicio
- Añadir campo subir_peso al PATCH /ejercicios/{id} para actualizarlo
- O crear endpoint dedicado: POST /ejercicios/{id}/sesion que recibe
  [{ejercicio_id, series, reps, peso, completado}] y guarda en lote + actualiza subir_peso

CAMBIOS FRONTEND NECESARIOS:
- En Diario.tsx, pestaña "Entreno Libre" (o tab "Fuerza" nuevo):
  detectar si hoy hay sesión de fuerza → mostrar formulario de registro
  Si no hay sesión de fuerza hoy → mostrar mensaje o formulario genérico
- El formulario muestra los ejercicios del grupo activo ese día
- Cada ejercicio: campos series, reps, kg + toggle completado
